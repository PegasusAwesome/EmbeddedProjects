This is for the ESP32xxx setup where we use an ESP32xxx, and disc with ws2812b's in ringwise setup

This project is meant to drive 93 leds. These leds are layout out in concentric rings. The circles have different sizes, so they all fit in one another. Circle sizes: 
1 led, 8 leds, 12 leds, 16 leds, 24 leds, 32 leds
